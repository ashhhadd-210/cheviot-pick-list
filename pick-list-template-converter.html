Cheviot Trees — Pick List Template Converter

Upload raw CSV files, group stock lines by bed/species, then download them directly into the Cheviot Pick List Excel template.

Instructions
Built-in template: updated pick list template.xlsx

The Excel export uses the updated Pick List worksheet as the layout shell. It clears the old row contents, writes the converted stock groups into columns A–N, and leaves the workbook's existing dropdowns, conditional formatting, widths, row heights and other workbook sheets intact. Column J remains the template's No frames = No trays ÷ 32 formula. Batch No is not needed at this stage.

Excel column mapping: B = plant size only, C = cell type only, and D = species name only. The original size description is shown in the converter for checking. For the Excel Pick List, descriptions such as Cell4 20/60 are split and normalised so 20/60 goes to column B and C4 goes to column C. Column C keeps the template's existing coloured conditional formatting. Load Date (K) is exported as a genuine Excel date and displayed as DD/MM/YYYY.

Manual columns: Progress (L) and Notes/Comments (N) are left blank in the downloaded Pick List. The Progress dropdown remains in Excel for manual selection.

Plant-only filter: genuine plant lines are recognised from their plant cell/grade or botanical species name. Delivery, packaging, stakes, canes, ties, fertiliser, guards, shelters, spirals and other accessories are excluded from the Pick List. Anything excluded is shown on the Excluded Items tab for checking before download.

Labels tab: select a delivery number to create the same outward delivery label used in the Batch Pick List. Match Code is linked from the highlighted Match Code row to the Delivery Number on its Sold: row. Delivery Number is the unique order identifier. One Match Code may have several delivery numbers, but each Delivery Number can have only one Match Code. A named Match Code column is also supported if one appears in a future export. The frame total is calculated from the plant quantity and cell type and rounded up to a whole outward frame.
